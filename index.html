Rice Seed Climate Ledger

Field-to-Finished-Seed Climate Accounting

Public Beta v7.0 — an open framework for testing, challenging and improving climate accounting across the physical journey of Indian rice seed.

PUBLIC BETA • SEPTEMBER 2026
Open the Data ValidatorDownload v7 Excel Template
This is deliberately a public beta. It is not presented as a finished carbon standard or verified carbon-credit methodology. The purpose is to expose the framework to practitioners, researchers, seed companies, agronomists and sustainability professionals so that they can test assumptions, identify omissions and improve the next version.
Scope

What is covered?

Parent seed → rice seed production field → harvest → drying → processing → storage → packaging → finished saleable seed.

Downstream commercial grain production is outside v1/v7 system boundary.

Core metric

What is calculated?

kg CO₂e per kg of finished saleable seed, with supporting views for total footprint, area intensity, methane contribution, activity breakdown and baseline/scenario comparison.

Validation

What does v7 add?

Real-data import structure, plot-level records, evidence IDs, mass-balance checks, data-confidence classification, factor governance and QA checks.

Challenge the framework

We want people to find what is wrong

What is missing? What factor is inappropriate? Which Indian data source should replace it? What activity have we overlooked?

Feedback should distinguish between calculation logic, emission factors, methodology applicability, Indian evidence, data requirements and system-boundary questions. Specific evidence is especially valuable.

  • Identify an emission factor that should be changed.
  • Point to an Indian or international source that should be considered.
  • Flag a possible double-counting issue.
  • Suggest a missing field activity or post-harvest activity.
  • Test the mass balance with real or anonymised records.
  • Challenge whether a factor is appropriate for seed production rather than grain production.
Methodology discipline

Evidence is classified

The framework distinguishes between approved/official methodologies, Indian scientific evidence, international defaults, technology-specific evidence and illustrative assumptions.

Unvalidated components are intentionally marked TBD / excluded rather than being given an unsupported default value.

Important limitation

What v7 does not certify

The validator checks data structure and basic consistency. It does not certify carbon factors, methodology applicability, additionality, permanence, evidence authenticity or carbon-credit eligibility.

How to test

Three simple ways to participate

  1. Run the validator: open validator.html and paste CSV records.
  2. Use the Excel template: populate anonymised or real seasonal data and test the field structure.
  3. Send feedback: use the repository's GitHub Issues to report a specific problem, preferably with the source or evidence supporting the suggestion.
Version governance

v7.0 status

Public Beta Open for review Not independently verified

About the project

The Rice Seed Climate Ledger is being developed as a practical field-to-finished-seed accounting framework for Indian rice seed production. The aim is to make the accounting transparent enough to be tested, challenged and progressively improved.

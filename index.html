Methodology

ANVORA distinguishes catalogue evidence, measured remote-sensing evidence and interpreted practice events. The application does not treat a satellite acquisition alone as proof of farm activity.

Technical details

For engineering, assurance and future maintenance. This section is deliberately separated from the normal user workflow.

Current architecture

  1. Browser selects plot and acquisition.
  2. Copernicus STAC supplies acquisition metadata.
  3. Authenticated ANVORA backend processes Sentinel-1 data.
  4. Measured statistics are stored with acquisition, plot and algorithm provenance.
  5. A validated event layer can interpret a measured temporal change.
  6. The user-facing observation must show the evidence image and plain-language conclusion.

Current limitations

  • Browser catalogue discovery can be affected by provider CORS/security rules.
  • Production processing requires valid server-side provider authentication.
  • A sandbox result is never treated as evidence.
  • Without a validated event model, ANVORA reports the measured signal but does not claim a farm practice.
